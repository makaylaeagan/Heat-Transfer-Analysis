# Heat Transfer Analysis

## Overview
This project uses MATLAB to analyze experimental cooling data for an aluminum cylinder submerged in an ice-water bath. The objective was to estimate the convective heat-transfer coefficient and model the transient temperature response of the cylinder using several numerical methods.

## Methods Used
- Newton-Raphson Method
- Numerical Differentiation
- Trapezoidal Integration
- Polynomial Regression
- Euler's Method
- Heun's Method
- Transient Heat Transfer Modeling

## Tools
- MATLAB
- Numerical Methods
- Heat Transfer
- Experimental Data Analysis

## Project Description
Experimental temperature measurements were analyzed in MATLAB to determine the cooling behavior of an aluminum cylinder. The convective heat-transfer coefficient was estimated from multiple experimental data points using the Newton-Raphson method.

Numerical differentiation and integration were used to analyze heat-transfer behavior, while polynomial regression was used to fit the experimental temperature data. Euler's and Heun's methods were also implemented to numerically solve the governing first-order differential equation and compare the predicted temperature response.
